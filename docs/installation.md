# Installation

django-bots supports Python 3.10 or newer and Django 5.2, 6.0 and 6.1.

Install the package:

```console
$ pip install django-bots
```

Add the app to `INSTALLED_APPS`:

```python
INSTALLED_APPS = [
    # ...
    "django_bots",
]
```

That's all the setup the package needs. Every feature is opt-in, and the pages in
this guide show how to turn each one on.
